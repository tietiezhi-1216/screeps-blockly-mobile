    3. 
    
  3. 点「完成」应用代码，再点「运行」让世界按 tick 运转，「1x」切换速度。
    4. 
    
  4. 单指拖动、双指缩放，点 creep / 建筑查看详情；「联机」可在同一 WiFi 下一起玩。
